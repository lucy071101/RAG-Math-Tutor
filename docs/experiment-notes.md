## 비교한 입력과 응답 방식

공통 질문: **“반지름이 8cm인 구의 부피를 구하는 방법을 알려줘”**

| 방식 | 설정 | 저장된 응답에서 관찰한 내용 |
| --- | --- | --- |
| 기본 RAG | MMR, k=3, fetch_k=10, RetrievalQA | 구의 부피 공식과 값 대입 중심의 응답 |
| 학습자 수준 지정 RAG | 유사도 검색 k=3, 교사 역할과 중학교 1학년 수준 지정 | 구·반지름의 의미부터 단계별 계산까지 풀어 설명 |
| LLM 단독 | 검색 문서 없이 같은 질문 입력 | 공식, 기호 설명, 값 대입과 계산 결과 제공 |

설명 방식의 차이는 확인되지만, 검색 방식과 프롬프트가 함께 달라졌기 때문에 이를 RAG 자체의 성능 향상으로 해석할 수는 없습니다.

## 관찰한 한계

1. **검색 관련성:** 구의 부피 질문에 대한 유사도 검색 첫 번째 결과가 ‘8cm 선 그리기’ 자료였습니다. 숫자나 표현이 비슷한 문서가 검색되더라도 수학 개념이 일치하지 않을 수 있음을 보여줍니다.
2. **계산 일관성:** 학습자 수준 지정 응답은 π=3.14를 사용한다고 설명하면서 약 2144.66㎤를 제시했습니다. π=3.14를 실제 대입하면 약 2143.57㎤이므로 설명과 결과가 일치하지 않습니다. 2144.66㎤는 π의 더 정밀한 값을 사용했을 때의 근삿값입니다.
3. **평가 범위:** 저장된 예시만으로 정확도·검색 품질·학습 효과를 일반화할 수 없습니다. 별도의 정량 평가나 사용자 만족도 수치는 없습니다.

이 PoC의 결과물은 데이터 문서화, 검색, 설명 생성, 응답 비교를 연결한 실험 파이프라인입니다. 답변이 자연스럽게 생성되는 것과 올바른 근거를 활용해 정확하게 설명하는 것은 별도로 검증해야 한다는 점을 확인할 수 있습니다.
